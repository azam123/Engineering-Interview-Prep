## Interview flow

```text
Gather requirements → Estimate scale → Draw high-level design
→ Define data model and APIs → Discuss bottlenecks
→ Explain security, scaling, reliability and observability
```

> The numbers in these documents are illustrative assumptions. In an interview, confirm the expected scale with the interviewer and explain your reasoning.
