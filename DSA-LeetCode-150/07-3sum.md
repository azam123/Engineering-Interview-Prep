# 7. 3Sum

- **Problem link:** https://leetcode.com/problems/3sum/
- **Difficulty:** Medium
- **Topic:** Array, Sorting, Two Pointers
- **Pattern:** Sort + fix one element + converging pointers
- **Data structure / algorithm:** Array, sorting, two pointers

## Problem Explanation

Return all unique triplets `[a,b,c]` such that `a + b + c = 0`. Duplicate triplets must be removed.

**Example:** `[-1,0,1,2,-1,-4]` → `[[-1,-1,2],[-1,0,1]]`.

## Clarifying Questions

1. Should triplets be unique? Yes.
2. Can values be negative or duplicated? Yes.
3. Can the same array index be used more than once? No.
4. Can the result be returned in any order?

## Brute Force Approach and Solution

Try every combination of three indices and use a set to remove duplicate triplets.

```csharp
public IList<IList<int>> ThreeSumBruteForce(int[] nums)
{
    var result = new HashSet<string>();
    var output = new List<IList<int>>();

    for (int i = 0; i < nums.Length; i++)
    for (int j = i + 1; j < nums.Length; j++)
    for (int k = j + 1; k < nums.Length; k++)
        if (nums[i] + nums[j] + nums[k] == 0)
        {
            var triplet = new[] { nums[i], nums[j], nums[k] };
            Array.Sort(triplet);
            if (result.Add(string.Join(',', triplet))) output.Add(triplet);
        }

    return output;
}
```

- **Pattern / DSA:** Enumeration + duplicate set
- **Time:** `O(n³)`
- **Space:** `O(m)` for results/deduplication
- **Drawback:** Cubic growth becomes impractical quickly.

## Optimized Approach and Solution

Sort the array. Fix `nums[i]`, then search the remaining suffix using two pointers. Skip duplicates at both levels.

```csharp
public IList<IList<int>> ThreeSum(int[] nums)
{
    Array.Sort(nums);
    var result = new List<IList<int>>();

    for (int i = 0; i < nums.Length - 2; i++)
    {
        if (i > 0 && nums[i] == nums[i - 1]) continue;
        if (nums[i] > 0) break;

        int left = i + 1, right = nums.Length - 1;

        while (left < right)
        {
            int sum = nums[i] + nums[left] + nums[right];

            if (sum == 0)
            {
                result.Add([nums[i], nums[left], nums[right]]);
                int leftValue = nums[left], rightValue = nums[right];
                while (left < right && nums[left] == leftValue) left++;
                while (left < right && nums[right] == rightValue) right--;
            }
            else if (sum < 0) left++;
            else right--;
        }
    }

    return result;
}
```

- **Time:** `O(n²)` after `O(n log n)` sorting
- **Space:** `O(1)` auxiliary space excluding output (sort implementation may use stack space)

## Dry Run

For `[-1,0,1,2,-1,-4]`, sort → `[-4,-1,-1,0,1,2]`. Fix `-1`; pointers find `-1 + 0 + 1 = 0` and `-1 + -1 + 2 = 0`. Duplicate `-1` is skipped.

## Is There a Further Optimized Approach?

For the general 3Sum problem, `O(n²)` is the standard target. Hashing can achieve similar asymptotic time but usually requires more memory and more duplicate handling.
