## How to use this repository

- Start with fundamentals, then move to scenario-based questions.
- Explain each answer aloud in 60–120 seconds.
- Practice the code examples and adapt them to production scenarios.
- Review trade-offs, security, scalability, observability, and failure handling.

## Suggested preparation cycle

```text
Concepts → Code Examples → Design Trade-offs → Scenario Questions → Mock Interview
```
